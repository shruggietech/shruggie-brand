# ESO Weave desktop specimen

This representative desktop screen demonstrates the Live HUD, System and State observations, combat-weaving controls, and fail-closed input gates described by the official product documentation. Open `index.html` after building the kit so its `../../styles.css` and `../../components/components.css` references resolve.

The specimen is intentionally bounded. It demonstrates the brand system and interaction hierarchy without defining new product behavior or claiming official ESO support.
