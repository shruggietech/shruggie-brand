# fragcap migration notes

The brand source was migrated from the operator's legacy generated kit.

- The existing full and reduced marks remain imported filled SVG paths without geometry changes.
- Signal Cyan remains the identity accent. Capture Orange remains inherited emphasis and is intentionally scarce.
- The original README, skill guidance, six icons, icon documentation, and web UI kit are carried forward as source material.
- Fragcap's bespoke historical build scripts are preserved under `docs/provenance/fragcap/build/`. They are not part of the canonical build path.
- Generated exports are rebuilt by CI and are not committed here.
