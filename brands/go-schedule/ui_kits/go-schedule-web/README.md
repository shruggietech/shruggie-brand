# go-schedule-web (demo UI kit)

A single-page product site built entirely from the go-schedule design system:
tokens, `components.css`, the outlined logo, and the ScheduleRow component. Open
`index.html` in a browser (it links `../../styles.css` and the kit assets).

Use it as a reference for composition, spacing rhythm, and how the schedule-first
components read in context. It is a demonstration surface, not production code.
