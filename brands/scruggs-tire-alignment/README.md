# Scruggs Tire & Alignment

Scruggs Tire & Alignment is an independent third-party client brand. The client owns its marks, services, and terms. This source folder follows the repository's standard brand schema and is independent of the supplied concept archive's file layout.

## Source artwork

The Full logo and tire-only mark are client-supplied PNGs embedded without modification in passive SVG source wrappers. The Full white-square image is the owner-reviewed visual. Transparent and black-square versions preserve the same tire and lettering shapes, with the black wording mapped to white only for the black ground. Native canvas wrappers bind the same Full image for horizontal lockups. Do not redraw, trace, normalize, or substitute type for any part of the mark.

## Production status

Gate 1 and Gate 2 approval records, the complete generated kit, and the public site projection govern production. The candidate evidence lives in ignored `dist/` and must not be committed as a generated artifact.
