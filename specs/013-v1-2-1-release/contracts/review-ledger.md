# Contract: S013 Review Ledger

## Allowed review sequence

1. Automatic Codex review triggered by the official pull request
2. Complete disposition and resolution of every received comment
3. No manual `@Codex` review request

## Finding policy

Every negative finding must be filed as a Phase 14 GitHub issue before its thread is resolved. The issue records the source discussion, severity, risk, acceptance criteria, labels, milestone, and relationship to #140. Warranted corrections are implemented and verified; rejected findings receive a concrete rationale.

## Completion

Review completes only when review records and body reactions have been inspected, every comment has a substantive response, warranted changes pass validation, and zero actionable threads remain unresolved.
