# S071 Data Model

## Working brief

Private schema version 2 records facts, constraints, proposals and unresolved decisions separately. Owner-supplied slogan and description are exact text; additional messages and social composition remain separately unresolved. Direction selection is recorded verbatim with date/source.

## Canonical candidate

Private brand.json plus glyphkit construction helper defines Full/Reduced paths, transparent evenodd counters, 1000-unit grid, framing, formal ink roles, typography and proposed affiliation. Packet binds source file hashes, identity snapshot, topology, qualified sRGB/OKLCH values, renderer and all 32 proofs plus comparison artifacts. Approval status remains pending.

## Approval and promotion

Lifecycle: exploratory -> direction-selected -> canonical-candidate -> canonical-approved -> promoted -> derivative-approved -> publication-eligible. Gate 1 binds exact source and proofs. Promotion copies those bytes. Governed drift invalidates the applicable approval rather than silently altering the source.

## Fundamentals and final kit

After Gate 1, private provisional derivatives feed the source-bound Gate 2 packet. Exact social-copy composition and canonical SVG/PNG digests need their own assembled-image decision. Final kit is generated only after both approvals and passes mandatory kit/glyph verification.

## Public projection

Official catalog, guidelines, assets, registry and downloads derive from the same verified version. Private candidates cannot enter public discovery. Existing source and geometry remain intact.

## Selected horizontal line layout

An optional logo.lockups.horizontal.wordmark_lines array records single-line text, role and positive finite font_size_units per row. Source-owned padding_units, gap_units, line_gap_units, mark_height_units and canvas_height_units determine layout. The text sequence must preserve wordmark_text. The rows align by visible left ink and form one vertically centered block beside the unchanged mark. New helper bytes join the renderer binding only for this opt-in layout; unconfigured brands retain their existing default path.
