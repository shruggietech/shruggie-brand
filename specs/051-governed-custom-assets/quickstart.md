# Quickstart

1. Add the supplied source file under the brand's `assets/source/` tree without modifying its bytes.
2. Add a `custom_assets` record with ownership or generator provenance, source format/hash, approval and publication fields, allowed transformations, usage, accessibility, credit/license, and contained preview guidance. Do not add it to core logo authority.
3. Run `brand_contract.py` and the brand build, verify, and glyph gates. Inspect PDF, portable, hosted topic, and downloads for inventory and presentation parity.
4. Do not commit `dist/`; commit the source file, manifest and documentation. Publication eligibility is explicit, not inferred from file presence.
