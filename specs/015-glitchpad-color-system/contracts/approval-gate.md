# Contract: Owner Identity Approval Gate

## Allowed dispositions

1. **Approve**: Name one direction and confirm its exact matrix or a fully enumerated approved matrix.
2. **Request bounded adjustment**: Name the direction, role, context, and replacement value or treatment to compare again.
3. **Reject**: Reject all current directions and state the next exploration boundary if known.

## Gate behavior

- Before approval, candidate values remain exploratory and no production identity source changes.
- A bounded adjustment returns Stage A to comparison generation and requires a new owner disposition.
- Approval authorizes only the named matrix and the production work already bounded by S015.
- The owner-established permanent square enclosure and prohibition of muddy deep gold govern every subsequent proposal. Any other geometry, hue-family, typography, texture, effect, or unrelated-brand change requires explicit expanded authority and fresh evidence.

## Required approval record

- Direction name and exact hexadecimal role matrix.
- Dark, light, permanent-square, square-edge, page, fold, reduced, monochrome, wordmark, and platform dispositions.
- Concise identity rationale and accepted tradeoffs.
- Date and owner confirmation.
