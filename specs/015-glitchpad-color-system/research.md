# Research: Glitchpad Identity Color Approval

## Decision: The square enclosure is permanent glyph geometry

**Rationale**: Owner clarification establishes that the Glitchpad glyph is always square-based and always contains the protected rectangular page-and-G construction. The square is not an optional launcher plate. Every full, reduced, lockup, desktop, Android, and store sample must therefore use the same square composition.

**Alternatives considered**: Add a square only in application contexts, which repeats the rejected structural misunderstanding; stretch the page into a square, which violates protected geometry; place a flush square into the legacy 800 by 1000 view box, which caused clipping in the rejected revision.

## Decision: Permanently reject muddy deep gold

**Rationale**: The owner explicitly rejected `#867100` as an identity color and prohibited its return. Revision 2 contains no muddy deep-gold candidate role. Saturated sulfur `#FFD900`, charcoal `#0B0C0D`, and cool slate `#667788` provide sufficient pairwise separation when the permanent square is used as the contextual boundary.

**Alternatives considered**: Retain deep gold only on light surfaces, which directly violates the owner decision; find a neighboring ochre, which preserves the rejected visual character; accept bright sulfur directly against white without a boundary, which does not satisfy non-text distinction.

## Decision: Compare sulfur placement within one fixed square composition

**Direction A, Sulfur Square**: A sulfur square contains a charcoal page and slate fold. The light-context square gains a charcoal edge so the saturated sulfur never needs to be darkened.

**Direction B, Charcoal Square**: A charcoal square contains a sulfur page and slate fold. A sulfur edge identifies the square on charcoal surfaces; on light surfaces the charcoal field supplies its own boundary. This is the revised recommendation because the sulfur belongs to the inner page while the permanent square solves contextual contrast.

**Direction C, Slate Square**: A slate square contains a charcoal page and sulfur fold. This preserves the legacy accent hierarchy while making the square unmistakable on both surfaces.

**Rationale**: The three directions now vary one meaningful identity decision, where sulfur belongs. All use identical square dimensions, safe inset, page scale, page placement, corner radius, stroke width, wordmark geometry, and sample layout. Pairwise internal contrast remains at least 3:1, and every declared square edge reaches 3:1 against its surface.

**Alternatives considered**: Vary square geometry along with color, which confounds the decision; use white as a fourth identity color, which is unnecessary; remove the fold from full marks, which weakens the page metaphor and makes full and reduced treatments less informative.

## Decision: Approval still precedes source promotion

**Rationale**: Constitution P2 requires an explicit owner decision, rationale, and comparison evidence for the new permanent square composition and its color roles. The study reads protected page paths but writes only ignored exploratory evidence.

**Alternatives considered**: Promote the owner clarification immediately, which skips approval of the resulting color system; patch generated files, which violates P1; treat contrast ratios as aesthetic approval, which they are not.

## Decision: Revision 3 uses a contextual square-and-page inversion

**Rationale**: The owner selected Sulfur Square for dark mode and Charcoal Square for light mode as a bounded mix-and-match proposal. The dark treatment gives the glyph an immediate sulfur silhouette; the light treatment changes the square to charcoal and moves sulfur to the page, avoiding both weak yellow-on-white boundaries and any muddy substitute. Slate remains the fold color and the wordmark remains neutral in both contexts.

**Measurements**: Dark square edge-to-surface is 13.34:1, charcoal page-to-square is 14.15:1, and slate fold-to-square is 3.33:1. Light square edge-to-surface is 18.41:1, sulfur page-to-square is 14.15:1, and slate fold-to-square is 4.25:1. Wordmark-to-surface is 16.90:1 dark and 18.62:1 light.

**Alternatives considered**: Keep one allocation across both contexts, which the owner did not select; darken sulfur for light mode, which is prohibited; vary the fold or wordmark at the same time, which would expand rather than isolate the bounded adjustment.

## Decision: Preserve protected page geometry and the monochrome contract

**Rationale**: The square is an enclosing construction around byte-identical page paths. The page is uniformly scaled and centered with safe inset, never redrawn or distorted. Black and white constrained outputs remain one-color square-plus-page compositions after approval.

**Alternatives considered**: Normalize the imported paths, stretch the rectangular page, derive a new G, or tint monochrome output, all of which are outside the approved clarification.
