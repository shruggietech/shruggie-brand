# Identity and Delivery Contract

1. **Visual identity**: The reviewed light stacked source presents the angular DWM lettermark above the upright outlined DANCEWITHME wordmark; 865 is white inside a solid red rectangle. The Full and Reduced icon marks remain DWM, not a newly substituted initial.
2. **Source integrity**: Selected SVG input bytes and paths remain exact. A source hash, role, crop, or renderer change requires a new Gate 1 candidate and proofs.
3. **Gate 1**: The owner receives exact source inventory, source revision and snapshot, provenance, palette qualification, framing, 32 production proofs, and four comparison artifacts per proof. Explicit approval binds the candidate ID and packet hash.
4. **Gate 2**: After Gate 1, the owner receives standard derivatives, typography, applications, and a distinct social share image with exact approved copy. Explicit approval binds the derivative manifest.
5. **Kit**: Approved brand source follows the existing repository schema. All required generated inventory is built through the existing pipeline, with governed exceptions only. The ZIP layout is never a deliverable contract.
6. **Publication**: The site reads the verified generated kit and states DanceWithMe865 as the client owner. Zero verifier problems, zero glyph failures, and WCAG 2.1 AA are required before the brand can be presented as shippable.
