# Quickstart: Verify Registry Delivery

1. Build all production kits using `python scripts/build_all.py` and confirm their normal kit and glyph gates pass.
2. Run `python scripts/test_registry_delivery.py` to validate every catalog and direct item against the pinned contract, then install representative generated payloads with `shadcn@4.21.0` in a temporary consumer.
3. Run `python scripts/test_prepare_site.py` and `pnpm --dir site build` to confirm public projection uses validated generated bytes.
4. Inspect each generated `nextjs/README.md`: the CLI installs theme and UI items; bundled fonts use the separate local-copy instructions.
5. After an authorized tagged release and deployment, compare public catalog/item endpoints with the released inventory and rerun the documented consumer install check against the public URLs. Record this evidence separately from PR verification.
