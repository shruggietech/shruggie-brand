# Social Image Contract

1. `social_copy` is mandatory for published production brands, with exact approved copy and selected layout. The compiler never falls back to `brand_idea`.
2. Canonical SVG and PNG are 1280 by 640. PNG is opaque, below 1 MB, and upload-ready as a repository Social Preview.
3. Full-color identity uses current mark and wordmark, or an unchanged approved supplied lockup when wordmark-only is unavailable.
4. Provenance and downloads classify the result as `social-image`, separate from logo lockups. Legacy `social-preview` files are identified aliases.
5. Every brand landing metadata image uses exact canonical kit PNG bytes at its stable URL. OG and Twitter metadata agree on path, size, type, and alt text.
6. Changing copy, geometry, or assembled image invalidates the corresponding approval binding and requires review of new proof.
