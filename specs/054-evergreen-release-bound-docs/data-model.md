# Data Model

The generated documentation publication record contains `schemaVersion`, inherited `status`, `version`, `tag`, `sourceRevision`, `releaseUrl`, `skillUrl`, `catalogSha256`, and ordered `references` and `pages` arrays. Each reference has a catalog-declared source and SHA-256. Each page has a route slug, path, and prepared-MDX SHA-256; the overview is included. Missing, extra, duplicate, and unsafe paths fail validation.

The page disposition lists each slug, source, reviewed stale-claim result, operative-rule cross-check, and change disposition. It is evidence, not a runtime authority.

The README contains no machine-owned brand inventory. Its audit checks stable destinations and snapshot patterns.
