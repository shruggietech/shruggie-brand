# Approval and Publication Contract

## Gate 1 source contract

- The packet contains exact Full and Reduced source candidates, role labels, hashes, allowed transformations, framing, palette qualification, topology/format verdict, renderer settings, and 32 proofs: four sizes times four surfaces times two mark roles.
- A reviewer can identify which current-site and ZIP references informed each candidate and which historical source was excluded.
- The explicit decision names the approver, date, source digest, and approved scope. An unchanged reference image or a proposed direction is not approval.
- Production source promotion copies approved bytes or reproducibly applies the approved construction helper. Drift returns to Gate 1.

## Gate 2 fundamentals contract

- The private packet references the approved Gate 1 source digest and checksums the Full, Reduced, wide, stacked, palette, interface cue, typography, representative application, social share image, and derivative manifest artifacts.
- Exact social slogan, optional description lines, line breaks, and layout are separate from the logo lockups and cannot be generated from `descriptor` by default.
- Accessibility evidence covers actual declared text/fill pairings. Any failing value or pairing is revised, then affected fundamentals return for review.
- The explicit decision binds exact derivative bytes and scope. A later creative change invalidates Gate 2; a changed production master invalidates both gates.

## Public output contract

| Surface | Required source and affiliation behavior |
| --- | --- |
| Showcase card and brand landing page | Consume verified generated values; name Scruggs Tire & Alignment as independent and client owned. |
| Guideline topics and downloads | Serve complete verified kit guidance and artifacts, with current brand provenance. |
| Registry endpoints and public metadata | Reflect the same approved brand source/version and third-party ownership. |
| Structured data and social preview | Avoid parentage or endorsement claims; use the approved distinct social composition. |

The website build must fail or exclude the brand when approvals, provenance, required kit contents, or verification are missing. Publication never relies on a ZIP manifest, a hand-written site palette, or a manually copied raster.
