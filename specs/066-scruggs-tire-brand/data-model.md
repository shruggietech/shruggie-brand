# Data Model: Scruggs Tire & Alignment Brand

## Reference evidence

Fields: source kind (`owner-request`, `current-site`, `zip-base`, `legacy`), observation date, location, hash when local, factual observation, authority classification, and intended use. Reference evidence never sets `approval_ledger` status by itself.

## Working brief

Use the repository's thirteen authoring topics. Each topic keeps separate facts, constraints, proposals, and unresolved choices. Social copy remains unresolved until exact slogan, optional description, line breaks, source, approver, and date are recorded. Private machine-checkable brief and Gate packets stay in ignored output.

## Brand source

Use the current `brand.json` schema with provisional id and slug `scruggs-tire-alignment`, kind `independent-brand`, `affiliation.ownership=third-party`, `inheritance=independent`, and `endorsement=none`. Select service credit explicitly. The source includes formal color roles, separate interface cues, licensed fixed-face metadata, authoritative input bindings or constructed-source provenance, logo variants, public-copy facts, and a vendor boundary. Do not create a second client-specific schema.

## Creative approval

Gate 1 binds the exact proposed production Full and Reduced masters, source hashes, renderer, mask or helper, framing, approved transformations, color qualification, proof matrix, approver, date, and scope. Gate 2 binds the approved Gate 1 source digest, provisional derivative manifest, exact social copy/image, formal and cue palettes, typography, lockups, representative applications, accessibility measurements, approver, date, and scope. Drift invalidates the relevant approval.

## Generated kit and public projection

The generated kit is a derived artifact with a manifest, provenance, guideline, logos, icon suites, specimens, tokens, component/framework bindings, and verifier results. Public projection consists of the showcase card, brand landing page, guideline topics, downloads, registry endpoints, public metadata, structured data, and social preview. Each public value derives from the verified kit. No generated artifact is committed.
