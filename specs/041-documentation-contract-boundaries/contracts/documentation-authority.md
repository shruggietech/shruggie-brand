# Contract: Documentation Authority

## Main manual

- Source pages live under `skill/references/` and are enumerated by `documentation-contract.json`.
- The manual owns compiler architecture, operating modes, canons, recipes, adapters, verification, conformance, versions, releases, installation, agent integration, and extension workflows.
- Every extension instruction names the authoritative source, generated outputs, validation entry point, and generated-output boundary.
- Main pages may link to child-brand examples but do not own their identity facts.

## Hosted child-brand reference

- Hosted facts originate in the verified generated kit and are staged from `guidelines/portal.json`.
- The hosted reference owns current public presentation of approved identity, assets, interface specimens, bindings, overrides, affiliation, and integration entry points.
- Shared compiler facts link to `/docs/` owners. Hosted pages do not copy system architecture or extension procedures.
- The hosted summary states the exact versions carried by the site build and never claims to govern older pinned kits.

## Bundled implementation contract

- `enforcement/consumer-contract.json` is the machine authority and `enforcement/IMPLEMENTATION.md` is its complete offline human-readable projection.
- The bundle owns exact local paths, version pins, semantic inputs, adapter locations, verification commands, recovery bytes and checksum, authority order, permitted exceptions, and capability-gap handling.
- Bundled guidance remains authoritative for delivered bytes after the hosted site advances.
- Recovery prefers delivered bytes, requires checksum validation, and never substitutes an unspecified latest release.

## Shared facts

`enforcement/documentation-facts.json` is the only record copied into both bundled Markdown and hosted portal data. Surface-specific prose may differ, but the required shared field values must not.

## Identity boundary

Shared documentation behavior cannot change a brand's ownership, affiliation, inheritance, approved artwork, geometry, palette, or provenance. Independent brands remain independent on every surface.
