# Authoring Workflow Contract

1. Gather and reuse operator material. For each follow-up, record the design decision it informs. Unanswered questions remain unresolved.
2. Discuss directions, palette, typography, copy, and applications without treating discussion or automated checks as creative approval gates.
3. Present real Full and Reduced production sources and complete proof matrix. Record explicit source-bound Gate 1 approval before derivative generation.
4. Assemble a private provisional packet with lockups, formal palette, separate interface cues, typography, representative uses, and a social share image showing exact approved copy and layout. Label social image separately from wide and stacked lockups. No public projection occurs yet.
5. Record explicit Gate 2 approval of exact reviewed fundamentals. Rejection returns to affected decisions; source changes return to Gate 1.
6. Compile the final kit, run documented verification, and separately authorize publication. Silence never approves either creative gate.
