# Contract: Gate 1 Source Authority

## Required packet

Gate 1 is private and hash-bound. It contains the complete in-scope inventory, grouped source previews, per-role authority proposal, guide-versus-source color measurements, font identity and licensing evidence, exact transformation proposal, unavailable deliverables, affiliation, privacy, credit, and publication classification.

The packet must explicitly state whether standalone main, secondary, submark, wordmark, and favicon sources were supplied. A PDF page, screenshot, extracted stream, or crop is not silently promoted to a standalone master.

## Approval conditions

Approval is valid only when the operator identifies one exact candidate revision and explicitly approves:

- every production source hash and role;
- every lower-authority or reference-only disposition;
- the exact display and body font binaries or an explicit no-binary fallback;
- every permitted transformation per source;
- the affiliation, privacy, service-credit, and publication values;
- the list of unavailable or intentionally omitted deliverables.

Silence, partial agreement, a revision request, approval of the visible idea, or approval of a different file does not authorize promotion.

## Invalidation

Any source byte, role, font, transformation, framing, color treatment, renderer, classification, or evidence change invalidates the affected approval. Implementation returns to Gate 1 before changing production source.
