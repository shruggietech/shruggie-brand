# Link Taxonomy Contract

| Family | Resting treatment | Interaction | Forbidden leakage |
| --- | --- | --- | --- |
| Editorial | Persistent offset subdued underline | Stronger underline and visible focus | Animated action line |
| Text action | Accessible accent, directional cue | Color change and visible focus | Native or decorative underline |
| Desktop navigation | Neutral text | Left-origin 2 px green line | Orange line or native underline |
| Mobile and footer utility | Neutral secondary text | Neutral-primary or accessible accent plus focus | Desktop line geometry |
| Button | Filled or outlined surface | Border, fill, focus, optional restrained transform | Any underline |
| Card | One linked surface with border focus | Component border or surface feedback | Descendant underline |
| Identity | Accessible-name image or text | Focus indicator | Text-link decoration |
| Contextual navigation | Component-owned current or directional treatment | Border or current indicator | Ordinary-link animation |

Editorial links alone may use visited color, and the visited value must retain contrast and underline. All discrete controls retain at least 44 pixels of target height. Reduced motion removes decorative transitions without removing state visibility.
