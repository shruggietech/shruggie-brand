# Data Model: Published Documentation and Guideline Integrity

## Instructional document

- **Identity**: Authoritative source path and declared publication destinations.
- **Fields**: Audience, format, reader-facing status, active compatibility terms, allowed exact exceptions, prepared-output path.
- **Validation**: Public copy has no work-slice codes, obsolete narratives, or unjustified process references. Instructions remain bound to current version facts.
- **Lifecycle**: Source reviewed → generated or copied → prepared public or kit output audited → published only after full verification.

## Integration delivery preview

- **Identity**: Existing delivery ID, format, source hash, and governed asset reference.
- **Fields**: Visual or nonvisual kind, declared appearance, visible artwork, chosen surface, surface text color, resource label.
- **Validation**: Visual artwork is discernible on its well; text and non-text contrast meet the applicable AA floor; nonvisual resources are labeled; source bytes remain unchanged.
- **Lifecycle**: Source asset → generated delivery metadata → preview decision → portable guide and hosted copy.

## Documentation transition

- **Identity**: Source and destination paths, optional fragment, and activation type.
- **Fields**: Viewport, motion preference, destination heading, final scroll position, active focus context.
- **Validation**: Fragment-free pagination lands at the destination beginning; explicit fragments retain their target; history and direct loads remain coherent.
- **Lifecycle**: Link activation → route commit → destination position and focus settled → optional browser history travel.
