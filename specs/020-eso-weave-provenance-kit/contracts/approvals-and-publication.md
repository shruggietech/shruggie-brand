# Contract: Derivative Approval and Publication

## Gate 1: Derivatives

Before any production derivative geometry is created, the owner receives:

1. exact authoritative files and hashes;
2. the mark's load-bearing characteristics;
3. every missing current-kit derivative;
4. a closed transformation boundary for each derivative;
5. eight comparison contexts per proposal (256, 64, 32, and 16 pixels on light and dark surfaces);
6. measured silhouette, bounds, alignment, spacing, and color differences;
7. one recommendation per proposal.

Approval is valid only for the named proposal ids and displayed source hashes. A pending, rejected, or stale record prevents derivative generation.

## Gate 2: Publication

After a complete private build passes, the owner receives:

1. source inventory and approval ledger;
2. final derivative comparison sheet and hashes;
3. rendered multi-page guide and PDF;
4. representative ESO Weave UI specimen;
5. complete verification results;
6. the exact proposed public surface list.

Approval is valid only for the displayed source hashes, derivative hashes, and enumerated surfaces. Until approval, ESO Weave must remain absent from site and public registry projections even if the kit builds successfully.

## Publication surfaces

The proposed set is: showcase card, brand landing page, guideline portal topics, downloads page and files, shadcn registry endpoints, generated public metadata and structured data, social preview, and routes required to reach those assets. Release publication is excluded.

## Failure behavior

Hash drift, a missing gate field, an unlisted surface, a prohibited claim, a missing vendor boundary, a verification failure, or an accessibility failure stops publication. There is no warning-only state.
