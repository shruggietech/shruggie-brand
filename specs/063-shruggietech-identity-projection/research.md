## Vivid rendered green

**Decision**: Qualify a source-bound reduced-mask derivation that produces opaque bright-green interior pixels while retaining antialiased edges and original shape. Review 16, 32, 48, and larger proofs against `#2BCC73` with a documented raster tolerance.

**Rationale**: The current luminance mask multiplies alpha by the maximum RGB channel, so a solid source green pixel becomes partially transparent and looks muted on black. A changed transformation requires exact proof and existing source approval.

**Alternatives**: Changing the color token alters the approved palette. CSS brightness repairs one surface only. A hard threshold loses antialiasing.

## Existing approved proof compatibility

**Decision**: Keep the i-heart-pr-tours renderer family bound to its approved record. After shared generator edits or a newer Node runtime change its version or settings hash, the canonical host must still generate all 32 approved PNG digests and exact comparison evidence. A portable host may use the existing measured comparison only when the canonical-host report has a valid report digest, matches the approved identity record and current renderer settings, and attests every exact approved PNG and comparison artifact. Without that attestation, the current host must match the approved matrix byte-for-byte.

**Rationale**: S063 changes shared generator code even when i-heart-pr-tours output is unchanged. The local and canonical CI host production matrices were 32 for 32 byte-exact against approval. Linux produced different raster bytes under the same candidate code. The attestation binds its measured cross-platform comparison to the candidate's exact canonical-host result, while a stale proof artifact or changed source settings fails before comparison.

**Alternatives**: Reapproving an unrelated identity or copying a frozen generator would expand the slice and duplicate logic. Requiring byte equality from every operating system would reject the already governed portable raster tolerance. Ignoring renderer drift without the exact canonical matrix would lose the source-bound approval.
