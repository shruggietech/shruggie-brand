**Decision**: Qualify a source-bound reduced-mask derivation that produces opaque bright-green interior pixels while retaining antialiased edges and original shape. Review 16, 32, 48, and larger proofs against `#2BCC73` with a documented raster tolerance.

**Alternatives**: Changing the color token alters the approved palette. CSS brightness repairs one surface only. A hard threshold loses antialiasing.

**Decision**: Keep the i-heart-pr-tours renderer family bound to its approved record. If shared generator edits or a newer Node runtime change its version or settings hash, allow the existing approval only when all 32 newly generated proof PNGs exactly match the approved digests and the comparison evidence remains exact. **Rationale**: S063 changes shared generator code even when i-heart-pr-tours output is unchanged. The local production matrix was 32 for 32 byte-exact against its approval. **Alternatives**: Reapproving an unrelated identity or copying a frozen generator would expand the slice and duplicate logic. Ignoring renderer drift without the exact matrix would lose the source-bound approval.
